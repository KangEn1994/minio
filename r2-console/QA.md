Known limits: this is an additional console service, not a replacement for MinIO's embedded Console. Per-bucket CORS and automatic lifecycle abort of incomplete multipart uploads are unsupported by the tested MinIO Community backend; manual abort is available. Bucket statistics exclude historical versions and scan at most 10,000 current objects; larger results are shown as lower bounds. Signed URLs are reachable only where the configured S3 endpoint is reachable. Cloudflare-only domains, analytics, billing, storage tiers, event queues and Data Access Logs are outside scope. R2 retroactive prefix locks do not map to MinIO S3 Object Lock. A public deployment URL was not available in the test environment; use the local or Docker instructions in `README.md` for a private deployment, or an HTTPS reverse proxy for remote use. The original MinIO source is archived upstream, so operators must assess maintenance risk before exposing this fork.
